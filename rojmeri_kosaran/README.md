# ڕۆژمێری کۆساران

## دامەزراندن
1. Node.js 22 یان نوێتر دابمەزرێنە.
2. لە PowerShell بچۆ ناو ئەم فۆڵدەرە.
3. `npm install`
4. `npm start`
5. لە براوزەر `http://localhost:3000` بکەرەوە.

## چوونەژوورەوەی سەرەتایی
- Admin: `admin` / `admin123`
- Staff: `staff` / `staff123`

دوای چوونەژوورەوەی Admin، لە بەشی **ڕێکخستنی یوزەر و پاسۆرد** دەتوانیت هەردووکیان بگۆڕیت.

## تایبەتمەندییە نوێکان
- کاتی هاتن و ڕۆشتن لە خانەی دروستدا نیشان دەدرێت.
- Admin دەتوانێت تۆماری هەڵە بسڕێتەوە.
- سڕینەوەی تۆمار ڕێگە دەدات کارمەند دووبارە هاتن تۆمار بکات.
- پەڕەی Staff بە تەواوی 100% شاشەیە و scroll ـی نییە.
- وتەی کورت و جوان هەر 1 خولەک جارێک دەگۆڕێت.
- کات بە 12-hour AM/PM نیشان دەدرێت.
